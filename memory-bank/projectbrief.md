# Project Brief: BaseWebCore

## Mục tiêu

BaseWebCore là một dự án .NET Core đóng vai trò là nền tảng cơ sở cho việc phát triển các ứng dụng web. Dự án này cung cấp các thành phần cốt lõi và cấu trúc cơ bản để xây dựng các dịch vụ web một cách nhanh chóng và hiệu quả.

## Phạm vi

-   Xây dựng cơ sở hạ tầng cho phát triển web API
-   Cung cấp các dịch vụ cốt lõi được sử dụng chung
-   Thực hiện các chức năng bảo mật và xác thực
-   Tích hợp các mô hình dữ liệu cơ bản
-   Hỗ trợ các tiêu chuẩn phát triển web hiện đại

## Yêu cầu cốt lõi

1. Kiến trúc đa tầng rõ ràng
2. Xác thực và phân quyền hiệu quả
3. Khả năng mở rộng dễ dàng
4. Hiệu suất cao
5. Bảo mật tốt
6. Dễ dàng tùy chỉnh và mở rộng

## Giới hạn

-   Dự án tập trung vào backend, không bao gồm phần frontend
-   Sử dụng .NET 8.0 làm nền tảng chính
